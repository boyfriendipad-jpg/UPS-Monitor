# UPS-Monitor Giving old UPS devices a second life!
Программа для мониторинга ИБП на Windows 10 и 11, помогаем оживить старые бесперебойники, получая с них данные по USB. Поддерживаем режимы USB HID и NAT (в NAT драйвер нужно установить вручную). Интерфейс простой, есть отчёты, есть история, и понятные уведомления для пользователя. Цель проекта — помочь пользователям следить за состоянием старых ИБП, чтобы они служили дольше, а техника была в безопасности.

UPS Monitor is a simple app for Windows 10 and 11 that helps you monitor older UPS devices. Our goal is to keep legacy UPS units useful by reading their data over USB, showing clean status information, saving logs, and sending clear alerts. We support USB HID and NAT modes. If you use NAT mode, please download and install the driver manually before connecting your UPS. The interface is simple, with reports, history, and clear notifications. Our goal is to help you keep old UPS units running longer and protect your equipment.

Support:Mustek,Delta,PowerCom.
